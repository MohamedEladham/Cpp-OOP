# C++ Object-Oriented Programming (OOP)

Welcome to my **C++ Object-Oriented Programming (OOP)** repository!

This repository documents my learning journey through Object-Oriented Programming in C++, featuring practical code examples and exercises that demonstrate the fundamental concepts and techniques of OOP.

The goal is to understand how these concepts work by implementing them through small, focused examples.

## 📚 Topics Covered

The repository includes practical examples covering the following topics:

### 1. Classes and Objects
- Classes and Objects
- Access Specifiers
- Properties, Getters, and Setters
- Encapsulation
- Nested Classes and Structures

### 2. Constructors and Destructors
- Default and Parameterized Constructors
- Copy Constructors
- Constructors and Destructors
- Object Initialization

### 3. Static Members
- Static Data Members
- Static Member Functions
- Static and Non-Static Member Functions

### 4. Inheritance
- Basic Inheritance
- Access Control in Inheritance
- Private and Protected Inheritance
- Multilevel Inheritance
- Function Overriding
- Inheritance Using Header Files

### 5. Polymorphism
- Upcasting and Downcasting
- Runtime Polymorphism
- Early and Late Binding
- Abstract Classes
- Pure Virtual Functions

### 6. Advanced Class Concepts
- Friend Classes
- Friend Functions
- Passing Objects by Value and Reference
- Storing Objects in Vectors
- Dynamic Arrays of Objects
- Initializing Arrays of Objects
